# Python Quest

Gamified Python learning platform built with Next.js, Supabase, and a secure Docker-based Python runner.

## Tech Stack
- Next.js App Router + TypeScript
- Tailwind CSS + shadcn/ui-style components
- Supabase (Auth + Postgres + RLS)
- Separate Node runner service for Python execution

## Quick Start
```bash
npm install
npm run dev
```

Runner service:
```bash
cd runner
npm install
npm run dev
```

Further setup instructions are completed in later implementation phases.
